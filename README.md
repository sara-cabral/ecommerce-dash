# Análise de Dados de E-commerce com Dash

Aplicação interativa desenvolvida em Python e Dash para visualização de dados de produtos de e-commerce.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly
- Dash

## Visualizações

A aplicação apresenta:

- Histograma
- Gráfico de dispersão
- Mapa de calor
- Gráfico de barras
- Gráfico de pizza
- Gráfico de densidade
- Gráfico de regressão

## Dados

Os dados utilizados estão disponíveis no arquivo `ecommerce_estatistica.csv`.
